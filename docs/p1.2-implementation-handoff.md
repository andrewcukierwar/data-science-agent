## Implementation limits

- Catalog membership, exact retained values, provenance, and stable identities
  are deterministic. Semantic relevance and entailment remain Critic judgment.
- Legacy validation evidence stays loadable with a null contract version. A
  nonempty legacy issue is adapted conservatively to an active blocker only
  when it crosses a new runtime validation boundary; persisted old evidence is
  not rewritten.
- Generalist repair is refused when the application cannot prove how many
  primary-agent responses consumed the original turn allowance.
- A repair invocation can succeed while its next validation still finds a
  blocker. The repair record reports invocation/persistence status; the latest
  validation snapshot remains authoritative for final status.
